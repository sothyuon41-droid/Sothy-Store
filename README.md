# Sothy Store
A simple clothing-store storefront built with HTML, CSS, and JavaScript.

## Pages
- Home(`html/index.html`): store introduction and featured clothing.
- Products (`html/products.html`): product listing.
- About (`html/about.html`): information about Sothy Store.
- Contact (`html/contact.html`): contact form layout.
- Cart (`html/cart.html`): example shopping-cart layout.

## Project structure
'text'
css/      Page stylesheets
html/     Store pages
image/    Product and storefront images
js/       JavaScript for the mobile navigation menu

## Run locally
No build step or package installation is required. Open `html/index.html` in a browser, or open the project folder in VS Code and use a local static web server to serve that file.

The cart and contact form are currently front-end layouts; checkout, form submission, and server-side functionality are not connected.
